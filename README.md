## 📌 Sobre o Projeto

O **VS Code Portfolio** é uma aplicação web desenvolvida em **Next.js (App Router)** e **TypeScript** para apresentar minhas experiências profissionais, projetos acadêmicos e habilidades em Análise de Dados e Desenvolvimento de Software de uma forma imersiva e interativa.

### ✨ Principais Recursos

- 💻 **Interface Fiel ao VS Code**: Inclui Activity Bar, Sidebar retrátil com árvore de arquivos, abas ativas, Editor de Código e Terminal integrado.
- 📱 **Modo Mobile Híbrido**: Renderização inteligente que carrega um *Feed Dev Clean* em dispositivos móveis, com a opção de alternar para a IDE VS Code com um clique.
- ⚡ **Terminal Interativo**: Permite a execução simulada de scripts em Python/JSON/Shell que exibem resumos de dados e experiências no terminal.
- 🎨 **Suporte a Múltiplos Temas**: Alternância dinâmica de temas populares de IDE (One Dark Pro, Dracula e Monokai).
- 📄 **Modo Leitura RH / CV**: Botão de acesso rápido para uma versão em documento do currículo, otimizada para leitura rápida e download em formato PDF.
- ⌨️ **Command Palette (`Ctrl + K`)**: Atalho global para busca rápida de arquivos e alteração de temas.

## 🚀 Como Executar Localmente

### Pré-requisitos
- **Node.js** (versão 18 ou superior)
- **npm** ou **yarn**

### Passo a passo

1. **Clone o repositório:**
   ```bash
   git clone [https://github.com/samirsousa/portfolio-ide.git](https://github.com/samirsousa/portfolio-ide.git)
   cd portfolio-ide
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Abre o seu navegador em:**
   ```bash
   http://localhost:3000

## 📦 Build e Deploy

O projeto é compilado como um site estático e enviado para a branch gh-pages:

```bash
npm run deploy
```
